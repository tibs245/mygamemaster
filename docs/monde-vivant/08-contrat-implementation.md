## 0. Cross-cutting Principles (Apply to ALL Scripts)

0.1 **Source of truth = files.** No script keeps state outside campaign files.

0.2 **Non-destructive.** The new files (`geo.json`, `acteurs.json`) are the **truth**
for 4D space and living-world actors. `monde.json`/`pnj.json`/`evenements.json` are
**read** (never rewritten by these scripts). Only **authorized and explicit** exception:
`causal_propagate.py --apply` and `world_tick.py` **append** events to a
**separate file** `evenements_programmes.json` (see §1 and §7), **never** to `evenements.json`.

0.3 **Campaign argument.** Each CLI script takes **as first positional argument** the
**path to campaign folder** (absolute or relative), exactly like `clock.py` /
`check_session.py`. Example reference used throughout this contract:
`<REPO_ROOT>/data/mj-tonnerre/campagnes/la-naissance-dun-roi`.
Scripts **don't guess** the campaign: they use the provided path.

0.4 **Exit codes (common convention).**
`0` success / nothing to report · `1` partial success or business condition reported (deadline passed,
crossing found, intention refused…) · `2` usage error / file not found / broken JSON.
(Identical to `clock.py`.)

0.5 **Mandatory atomic writes** (reuse `faction_slice.py` pattern): tmp in same folder →
`flush` + `os.fsync` → `os.replace`. `json.dump(..., ensure_ascii=False,
indent=2)` + final `"\n"`.

0.6 **Fail-open at runtime.** Everything called in the **game loop** (context assembler,
state reading) must **never** crash a turn: on missing or corrupted data → return an
**empty/degraded** result and a message to `stderr`, code `0`. **Write** tools
(tick, propagation, `creer_lieu`, `deplacer`) **may** fail hard (code `1`/`2`)
because they run outside the narration loop.

0.7 **Encoding.** UTF-8 everywhere. Human messages in French with markers consistent with
existing code (`✅ ⏱ ⏰ 🔴 🟠 🟢 ℹ ❌`).

0.8 **The LLM doesn't compute.** No script in this contract calls an LLM **directly**.
The LLM *seam* (`agent_decide`) is a **boundary function**: `world_tick.py` exposes it but its
realization (call `hermes -p`, `gemma-4`) is **injectable** and outside pure-code scope (see
§7.5). Aligns with project preference (avoid Gemini; **gemma-4** for structured decision).

0.9 **No dependencies between new scripts at import level except via `worldlib`.**
`geo_query`, `world_tick`, `causal_propagate`, `scene_brief` **all import** `worldlib`
(never the reverse) and may call **each other as subprocesses** (CLI) but **don't import** one
another, to enable parallel development. (`world_tick` may import `causal_propagate`
and `geo_query` as **modules** — these are the only inter-script dependencies allowed, see
§7.)

## 2. ID Conventions (Frozen, with REAL Campaign Examples)

### 2.1 General Form

```
<type>:<path-kebab>
```

- `type` ∈ { `lieu`, `region`, `ville`, `acteur`, `faction`, `comte`, `evt`, `intent`, `rel` }.
- `path-kebab`: lowercase ASCII, words separated by `-`, **levels** separated by `/`.
- **Deterministic slugification** (function `worldlib.slug`): NFKD → remove diacritics
  → lowercase → all characters outside `[a-z0-9]` become `-` → squeeze `-` → strip `-`.
  Ex. "Cabane de Berthe" → `cabane-de-berthe`; "Sceau n°6 — Limite Nord" → `sceau-n-6-limite-nord`.
  **Note**: `n°6` gives `n-6` (the `°` and space become `-`). The IDs below are the
  **canonical form ADOPTED**; if there is discrepancy with raw slugification, **the ID in the table
  takes precedence** and is entered as-is in `geo.json` (slugification serves to *propose*, not to
  *impose*).

  type)`. Optional `id` field `rel:<src-slug>-<type>-<dst-slug>` if need to reference it.

  (the PC founds one) — we don't create them by default.

### 3.3 Time Conversion `T ↔ day/hour` (ONLY bridge)

`T` is an **integer ≥ 0** in **UT**, `T=0` = campaign creation, monotone. **The player never
sees `T`.** All conversion passes through these functions (no calendar elsewhere).

```python
def t_vers_jour_heure(T: int) -> tuple[int, int, int]:
    “””T (UT) → (day, hour, minute). day starts at 1: day = T // 144 + 1.
    hour 0–23, minute ∈ {0,10,20,30,40,50}. Ex. T=0 → (1, 0, 0).”””

def jour_heure_vers_t(jour: int, heure: int = 0, minute: int = 0) -> int:
    “””Inverse. day ≥ 1. T = (day-1)*144 + hour*6 + minute//10.”””

def t_vers_narratif(T: int) -> str:
    “””BLURRED render for narration, never raw T. Ex. 'Day 58, late afternoon'.
    Frozen hour bands: 0-4 night · 5-7 dawn · 8-11 morning ·
    12-13 noon · 14-17 afternoon · 18-19 late afternoon · 20-21 evening · 22-23 night.”””

def parser_duree_minutes(texte: str) -> int:
    “””Parse narrative duration ('2h', '30min', '1h30', '~4h', '5h45 — desc') to
    MINUTES. -1 if unparseable. (Same semantics as validator-distances.extraire_minutes;
    reuse/recopy the proven regex.)”””

def minutes_vers_ut(minutes: int) -> int:
    “””DETERMINISTIC rounding to nearest UT via stdlib round() (banker's rounding:
    34.5→34), minimum 1 if minutes>0. Ex. 40min→4, 90min→9, 20min→2, 345min→34.”””

def t_courant(campagne: Path) -> int:
    “””Current campaign T (UT), DETERMINISTIC and fail-open. Resolution order:
      1) max of INTEGER 't' in evenements_programmes.json (status resolved);
      2) else, derived from max 'Day N' in monde.json>etat_global.chronologie + sessions/*.json
         via jour_heure_vers_t(day_max, 12, 0)  (noon by default);
      3) else 0.
    NEVER reads evenements.json as integer (its 't' are STRINGS 'Day N…').
    Reuses the 'Day N' heuristic from clock.jour_courant.”””
```

> **Bridge with existing code.** `evenements.json` stores **textual** `t` (“Day 7, late
> afternoon”): we don't convert them in place (non-destructive). `t_courant` derives `T`
> from the **largest “Day N”** encountered → noon of that day. The real campaign is at **Day 7**
> (S8) → `t_courant ≈ jour_heure_vers_t(7,12,0) = 6*144 + 12*6 = 936` (see §9 for calibration).

### 3.6 MDS Anchoring — **Pure Stdlib** (Duration Matrix → `(x,y)`)

**SMACOF** implementation (stress majorization, Guttman transform), sufficient for dozens
of places. Prototype validated on real campaign matrix: **normalized stress
≈ 0.16** on **incomplete** data (16 edges, 13 nodes) — well enough for **coarse**
non-metric anchoring. No external libs.

```python
def matrice_durees(geo_ou_deplacements) -> tuple[list[str], list[list[float]]]:
    """Build dissimilarity matrix (in UT):
      - input = dict deplacements (regles.temps.deplacements) OR geo graph;
      - extract pairs (place_a, place_b, minutes) via parser_duree_minutes,
        map labels to IDs §2.2, convert to UT;
      - complete missing pairs via shortest path (Floyd-Warshall);
      - return (ordered_ids, D) with D[i][j] symmetric, diagonal 0."""

def ancrer_mds(ids: list[str], D: list[list[float]],
               iterations: int = 300, seed: int = 42) -> dict[str, dict]:
    """SMACOF stdlib. Return {id: {'x': int, 'y': int}} centered (centroid at 0) and
    rounded to integer. Deterministic (frozen seed). Unit: ~1 UT travel ≈ 1 plan unit
    (internal scale, NEVER shown to LLM)."""

def stress_normalise(ids, D, coords: dict[str, dict]) -> float:
    """sqrt( Σ(d_ij - D_ij)² / Σ D_ij² ). Anchor quality indicator."""
```

> **MDS Guarantees.** Determinism (seed); termination (bounded iterations); coordinates
> **non-metric** serving code only (radius, crossing, proximity sort); **never**
> exposed to LLM (invariant `01`§C).

### 3.7 Trajectories (Position = Function of Time)

A trajectory is a **list of segments** sorted by `de` ascending, with no gaps or
overlaps (invariant `01`§5.3). Two segment forms:
- **stay**: `{"lieu": "<id>", "de": T0, "a": T1}` (`a:null` = current/undefined);
- **movement**: `{"type":"deplacement","de":T0,"a":T1,"chemin":["<id>",…],"motif":"…"}`.

```python
def position_a(geo: dict, trajectoire: list[dict], T: int) -> dict:
    """Position of entity at instant T. Returns:
      {'lieu': '<id>', 'x': float, 'y': float, 'en_mouvement': bool, 'segment': idx}.
    - active stay → place + anchor of that place, en_mouvement=False;
    - active movement → interpolates (x,y) along 'chemin' proportional to time
      between successive anchors; 'lieu' = id of closest current edge,
      en_mouvement=True.
    If T before 1st segment → 1st place; after last (a=null) → last place."""

def valider_trajectoire(geo: dict, trajectoire: list[dict]) -> list[str]:
    """Return LIST of violations (empty = valid):
      - reference: all 'lieu'/'chemin' point to existing ID;
      - continuity: adjacent segments (a[i] == de[i+1]), no overlap;
      - real path: a 'deplacement' follows consecutive existing edges;
      - no teleportation: (a-de) >= sum of edge temps_ut;
      - monotonicity: de <= a (except a=null). (Check 'not in past' done
        at caller level with T_courant.)"""
```

```python
    'acteurs':[{'id':…,'distance':float}]} within radius (anchor) around point_id at T."""

def croisement(campagne: Path, traj_a: list[dict], traj_b: list[dict],
               seuil: float, pas_ut: int = 6) -> list[dict]:
    """Intersection of two trajectories. Samples T by 'pas_ut' step (def. 1h)
    over common interval; for each T, calculates anchor distance between two
    positions; returns WINDOWS where distance <= threshold:
      [{'T':int,'lieu':'<id approx>','distance':float,'narratif':str}].
    This is the EXACT calculation of 'does the player cross the migration / raid?'."""

def creer_lieu(campagne: Path, nom: str, depuis: str, dir: str,
               distance_m: int, *, type_lieu: str = "lieu",
               parent: str | None = None, apply: bool = False) -> dict:
    """DECLARATION of new place (LLM doesn't give (x,y)). Code:
    computes anchor = anchor(depuis) + vector(dir, distance_m→scale), forges ID
    (slug, under 'parent' or region of 'depuis'), creates reciprocal edge depuis<->id
    (temps_ut = minutes_vers_ut(distance_m→estimated duration)), VALIDATES (invariants §5), and
    if apply → writes geo.json (atomic). Returns {'id':…,'noeud':…,'violations':[…]}.
    'dir' ∈ {N,NE,E,SE,S,SO,O,NO}. Refuses (violations non-empty) if attachment bad."""

def deplacer(campagne: Path, entite_id: str, vers: str, depart_t: int,
             *, motif: str = "", apply: bool = False) -> dict:
    """DECLARES actor movement: builds edge 'chemin' (plus_court_chemin)
    from entity's current position (at depart_t) to 'vers', deduces duration
    (sum temps_ut), APPENDs movement segment then stay to actor's trajectory in
    acteurs.json, VALIDATES (valider_trajectoire + monotonicity vs t_courant), and
    if apply → writes acteurs.json (atomic). Returns
    {'entite':id,'segments_ajoutes':[…],'arrivee_t':int,'violations':[…]}."""
```

## 8. `causal_propagate.py` — Causal Propagation (Bounded)

Imports `worldlib`. CLI: `propager` (+ utilities). **Only** writes to
`evenements_programmes.json` (append) in `--apply` mode.

### 8.1 Bounding Constants (Frozen)

```python
PROFONDEUR_MAX = 4      # cascade doesn't go infinite (safeguard 1)
SEUIL          = 0.15   # below this significance threshold, wave dies (safeguard 2)
ATTENUATION    = 0.6    # factor (<1) applied at each hop (safeguard 3, guaranteed termination)
BUDGET_PAR_SOURCE = 16  # max derived events per root event (safeguard 4)
```

### 8.2 Frozen Signature

```python
def propager(evt: dict, profondeur: int = 0, *,
             campagne: Path, acteurs: dict | None = None,
             budget: list[int] | None = None,
             emis: list[dict] | None = None) -> list[dict]:
    """Multi-level causal propagation, BOUNDED and DETERMINISTIC. Returns list of
    derived 'programme' events (flat). Algorithm (cf. 04§2):
      if depth > PROFONDEUR_MAX: return;
      if evt['significativite'] < SEUIL: return;
      if budget exhausted (BUDGET_PAR_SOURCE): return;
      for each outgoing relation of evt node (acteurs.json):
        effect = regle_de_propagation(evt['type'], relation)   # deterministic
        if effect is None: continue
        evt_derive = programmer_evenement(
            target          = relation['vers'],
            T               = evt['T'] + relation.get('delai_ut', 0),
            type            = effect['type'],
            significativite = evt['significativite'] * relation.get('poids', relation.get('intensite',0.5)) * ATTENUATION,
            cause           = evt['id'],
            statut          = 'programme')
        emis.append(evt_derive); budget[0]-=1
        propager(evt_derive, depth+1, …)                      # bounded recursion
    NEVER recalculates past: only schedules FUTURE events (T >= evt['T'])."""

def regle_de_propagation(type_evt: str, relation: dict) -> dict | None:
    """DETERMINISTIC table (type_evt, relation.type) → effect {'type':…} or None.
    Ex.: (raid|pillage, predation) → 'pression_locale'; (penurie, approvisionnement)
    → 'penurie'; (penurie, vassalite) → 'appel_a_l_aide'; (incendie, approvisionnement)
    → 'penurie'. Campaign-extensible; unknown pairs → None (wave has no effect)."""

def programmer_evenement(*, cible: str, T: int, type: str,
                         significativite: float, cause: str,
                         statut: str = "programme") -> dict:
    """Factory a PROGRAMME event complying with evenement_programme.schema.json (§8.3).
    id = 'evt:<type>-<T>' (zero-padded for uniqueness)."""

def appliquer(campagne: Path, evenements: list[dict]) -> int:
    """Atomic append of events to evenements_programmes.json. Returns count written.
    Creates file (with meta) if missing. NEVER to evenements.json."""
```

```python
def scene_brief(campagne: Path, lieu_id: str, T: int | None = None,
                rayon: float = 120.0, fenetre_ut: int = 432) -> dict:
    """Build scene brief. Default T = worldlib.t_courant. Returns:
      {'T':int,'lieu':lieu_id,
       'autour':[{vers,dir,distance_m,temps_ut}],   # geo_query.voisins
       'contenus':[id…],
       'presents':[{id,nom,type}],                  # geo_query.qui_est_a (place+radius)
       'mouvement':[{acteur,T,lieu,narratif}],      # upcoming crossings (warm actors)

       'texte':str}                                 # compact render (cf. 9.2)
    δ = fenetre_ut (def. 432 UT = 3 days)."""
```

### 9.2 EXACT Text Format of SCENE BRIEF (Frozen)

Boxed block, **~1 screen**, FR, that the GM "learns to read" (like Steward's "Persisted" block).
The returned `texte` follows **exactly** this template (lines omitted if empty):

```
┌─ SCENE BRIEF ─ T=936 (Day 7, late afternoon) ────────────────────┐
│ LIEU      lieu:marche-aux-trois-rivieres/cabane-berthe — "Berthe's│
│           Cabin, at the edge of the Marche"                       │
│ AUTOUR    S → wild sloe (20min) · O → charm woods (40min) ·       │
│           O → Firmin's cabin (1h30) · NE → stone house (1h30)     │
│ PRÉSENTS  acteur:berthe (Berthe, ally) · acteur:rousset (Rousset) │
│ MOUVEMENT acteur:drageon en route to Ford (return ~D11) ;         │
│           raven-band: scheduled raid (not visible) by latest      │
│           in ~3 wks → crosses cabin if undefended                 │
│ RÉCENT    D7 reunion at cabin; D6 meeting with Esterlin           │
│ IMMINENT  ⏰ Drageon's return (Raven's reply) ~D11                │
│ ENJEUX    raven-band (predation .4) lurks at Ford ;               │
│           silver-shore-counts: Esterlin's favorable report        │
└────────────────────────────────────────────────────────────────────┘
```

Frozen render rules: header `T=<int> (<narratif>)`; column labels **exact**
(`LIEU AUTOUR PRÉSENTS MOUVEMENT RÉCENT IMMINENT ENJEUX`); durations in **narrative**
(`t_vers_narratif`/`duree_narrative`), **never** raw `T` nor `(x,y)`; `⏰` for scheduled
events; target width 74 columns (soft truncation, no error if exceeded).

```

```

`--json` → returned object; default → `texte`. Code `0` **always** (fail-open), except usage
(`2`) if campaign not found.

## 14. Inter-Agent Coherence Invariants (NEVER Violate)

1. **`T` is UT integer, monotone, `T=0` at creation.** All conversion via
   `worldlib` (§3.3). Player never sees `T` (always `t_vers_narratif`).
2. **LLM never produces `(x,y)` or `T`.** It declares relative/narrative; code
   computes (`creer_lieu`, `deplacer`, validated `agent_decide`).
3. **Non-destructive**: no script in this contract writes to `monde.json`, `pnj.json`,
   `evenements.json`, or existing hooks/scripts. Writes **only** to
   `geo.json`, `acteurs.json`, `evenements_programmes.json` (+ schemas/tests at build).
4. **Frozen IDs**: those in §2 tables are truth; all new IDs follow `type:kebab`
   hierarchical form and pass through `worldlib.slug`.
5. **Conservation**: resources (extended Steward), space (no teleportation: duration ≥ sum
   of edges), time (monotonicity), causality (`delai_ut`, bounded propagation §8).
6. **Fail-open in game loop** (`scene_brief`, reads); **fail-hard** outside loop
   (`build`, `pre/post --apply`, `propager --apply`).
7. **Pure stdlib**: no external dependencies; MDS implemented by hand (§3.6).
